# LEO PNT Receiver (Aalto University)

This repository contains a modified version of the GNSS-SDR framework, specifically tailored for LEO (Low Earth Orbit) PNT (Positioning, Navigation, and Timing) research.

## Project Overview
This work is based on the open-source [GNSS-SDR](https://gnss-sdr.org/) project. The modifications included here are part of the research conducted for the LEO PNT receiver at Aalto University.
